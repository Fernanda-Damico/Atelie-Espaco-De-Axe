# 🌿 Ateliê Espaço de Axé — Plataforma Web & Catálogo Digital

Aplicação web responsiva desenvolvida para o **Ateliê Espaço de Axé**, projetada para apresentar produtos artesanais, facilitar o contato comercial e gerenciar o catálogo de forma dinâmica.

🔗 **Acesse o site online:** (https://www.atelieespacodeaxe.com.br)

---

## ✨ Funcionalidades

* **Vitrine Digital Responsiva (`index.html`):** Exibição organizada de peças artesanais e temáticas com navegação fluida para dispositivos móveis e desktop.
* **Painel Administrativo (`painel.html`):** Interface dedicada para gerenciamento e atualização dinâmica dos itens exibidos na loja.
* **Página de Erro Customizada (`404.html`):** Tratamento de rotas inexistentes para manter a identidade visual e a experiência do usuário.
* **Hospedagem e Banco em Nuvem:** Integração com o ecossistema Firebase para entrega rápida de conteúdo estático e persistência de dados.

---

## 🛠️ Tecnologias Utilizadas

* **Front-end:** HTML5, CSS3, JavaScript (ES6+)
* **Cloud & Infraestrutura:** Firebase Hosting, Cloud Firestore
* **Versionamento & Deploy:** Git, GitHub, Firebase CLI
